# Historical note: superseded sacred-geometry prototype

The original beta.1 prototype used a standalone pattern explorer with predefined patterns (Flower of Life, Seed of Life, etc.). It has been superseded because it did not express the emotional and relational mathematics of Trochos.

As of 2.0.0-beta.3, **Trochos 2.0 is the default `index.html`** and `/sacred-geometry.html` redirects there. The original trochoid mathematics and exact 1.1 construction are preserved. The additional sacred geometry derives from each glyph's actual curves instead of mapping emotions to motifs. See [the authoritative specification](semantic-geometry.md).

Historical and cultural contexts remain separate from the glyph's invented mathematical semantics in the main viewer. The retired pattern gallery is preserved in Git commit history for auditability but is no longer part of the active application.
